# Audit materials: Lunas Clinical Evidence KG v0.2.1

Scripts, exact SQL, result tables, reproducibility manifests and audit write-ups behind the numbers in the preprint
*Lunas Clinical Evidence Knowledge Graph*. Everything here is computed from the public release files: the 107 node and
edge files of v0.2.1. Nothing reads a production database, a non-public build or the separately licensed
annotation layer, and nothing needs credentials.

## Read this before relying on the release-wide audit

- **It ran against v0.2.0, not v0.2.1.** The release-wide audit (`release_audit/`) was run on release v0.2.0 (Zenodo 10.5281/zenodo.24091964,
  tag `clinical-v0.2.0`). All 107 node/edge files of v0.2.1 have the same SHA-256 as the v0.2.0 files (checked for this deposit), so statements about graph
  content hold for v0.2.1. Statements about the release metadata files (dataset card, citation file, exporter commit) describe v0.2.0. The
  lanes were run on v0.2.1 itself.
- **Comparisons with earlier builds are not included.** The original audit also compared v0.2.0 with release v0.1.0 and with an unreleased
  pre-correction build. Those need other files and cannot be reproduced from here; see [`EXCLUDED.md`](EXCLUDED.md). One consequence: the
  finding that 38 merged BACKGROUND/DERIVED role-pairs lost a prior `aact` source label is not in this deposit, because it is a difference
  between the unreleased build and the release.
- **Counts are censuses, examples are purposive.** The 18 path examples and 6 ranking queries are illustrations, not relevance judgments or
  benchmarks. Citations, RESULT/BACKGROUND/DERIVED roles and shared descriptors are not evidence of trial success, guideline endorsement or
  clinical quality; the "cited by a guideline or SR" counts are lower bounds (only citations inside the graph).
- **`code_commit` fields** in result files record the commit of this repository that was checked out when the script ran (the parent of the
  commit that added `audit/`). The exact scripts are pinned by the SHA-256 values in the manifests.
